# Kenzy QA Copilot - Бэкенд

- [English](README.md)
- [Русский](README.ru.md)

FastAPI сервис, обеспечивающий функциональность QA-помощника.

## Функции

- Автоматическая генерация тест-кейсов: создание e2e UI/API тестов на основе спецификаций
- Анализ дефектов: выявление проблемных зон и рекомендаций на основе истории дефектов
- Генерация ручных тест-кейсов: создание Allure TestOps-as-Code из требований
- Коммит тест-кейсов: фиксация тестов в GitLab
- Оптимизация тест-кейсов: обнаружение дубликатов, пробелов и улучшений
- Валидация тест-кейсов: проверка соответствия стандартам Allure и паттерну AAA
- Генерация тест-планов: создание краткого, структурированного тест-плана на основе целей, области применения и рисков

## Требования

- Python 3.13+ (рекомендуется)
- pip и virtualenv

## Настройка

1. Создайте и активируйте виртуальное окружение:
   - `python -m venv .venv && source .venv/bin/activate`
2. Установите зависимости:
   - `pip install -r requirements.txt`
3. Настройте окружение:
   - `cp .env.example .env`
   - Установите необходимые значения (см. ниже)

### Обязательные переменные окружения

- `APP_ORIGINS` — CORS origins через запятую (по умолчанию: \*)
- `GITLAB_ACCESS_TOKEN` — Личный токен доступа GitLab
- `OPENAI_API_KEY` — Токен Cloud.ru Evolution Foundation Model
- `OPENAI_API_URL` — Базовый URL API (по умолчанию: https://foundation-models.api.cloud.ru/v1)
- `OPENAI_MODEL` — Название модели (по умолчанию: ai-sage/GigaChat3-10B-A1.8B)

## Локальный запуск

```
uvicorn app.app:app --reload --host 0.0.0.0 --port 8000
```

Документация API после запуска:

- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

## Тестирование

- Запуск тестов: `pytest`
- Тесты находятся в `tests/`

## Структура проекта

- `app/` — FastAPI приложение, роутеры, сервисы
- `tests/` — Автоматизированные тесты
