# Kenzy QA Copilot - Фронтенд

- [English](README.md)
- [Русский](README.ru.md)

React 19 + Snack UIKit UI для QA-помощника.

## Функции

- Автоматическая генерация тест-кейсов: создание e2e UI/API тестов на основе спецификаций
- Анализ дефектов: выявление проблемных зон и рекомендаций на основе истории дефектов
- Генерация ручных тест-кейсов: создание Allure TestOps-as-Code из требований
- Коммит тест-кейсов: фиксация тестов в GitLab
- Оптимизация тест-кейсов: обнаружение дубликатов, пробелов и улучшений
- Валидация тест-кейсов: проверка соответствия стандартам Allure и паттерну AAA
- Генерация тест-планов: создание краткого, структурированного тест-плана на основе целей, области применения и рисков

## Требования

- Node.js 22+ с npm

## Настройка

1. Установите зависимости: `npm install`
2. Скопируйте файл окружения: `cp .env.example .env`
3. Установите `PUBLIC_API_BASE_URL` (по умолчанию `http://localhost:8000`)
4. Запустите dev-сервер: `npm run dev` (откроется http://localhost:3000)

## Скрипты

- `npm run dev` — запуск Rsbuild dev-сервера
- `npm run build` — продакшн сборка
- `npm run preview` — предпросмотр продакшн сборки
- `npm run lint` — запуск ESLint
- `npm run format` — форматирование с помощью Prettier

## Структура проекта

```
src/
├── components/            # Переиспользуемые UI-компоненты (например, Layout)
├── pages/                 # Страницы функций
├── services/              # Вспомогательные функции API-клиента
├── utilities/             # Общие утилиты/константы
├── theme/                 # Провайдер темы и настройка Snack UIKit
└── types/                 # Общие TypeScript типы
```

## UI/Технологический стек

- React 19, TypeScript, React Router 7
- Rsbuild для сборки; Snack UIKit для компонентов

## Заметки по разработке

- Убедитесь, что `PUBLIC_API_BASE_URL` указывает на бэкенд (локально: `http://localhost:8000`)
- Используйте `npm run lint` и `npm run format` перед отправкой изменений
